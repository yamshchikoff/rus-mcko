# Фаза: Интеграция реальных вариантов ВПР

**Дата:** 2026-06-04
**Статус:** ожидание URL сайта-источника

## Назначение

Взять реальные варианты контрольных работ ВПР для 7 класса с сайта-источника, извлечь их и прикрепить к проекту как эталонный материал. Поднять минимальный фронтенд для взаимодействия с вариантами. На следующей фазе — прикрутить к фронтенду ИИ-репетитора.

## Контекст

Варианты на сайте-источнике находятся в «откровенно непригодном к тренировке виде» — вероятно, это HTML-страницы с перемешанными заданиями, ответами, критериями оценивания, без разделения на отдельные задания и без интерактивности.

## Задачи фазы

### 1. Извлечение вариантов

- Получить доступ к сайту-источнику (URL ожидается)
- Извлечь все доступные варианты ВПР для 7 класса
- Извлечь необходимые куски фронтенда (HTML/CSS/JS), относящиеся к отображению заданий
- Сохранить извлечённые материалы в `data/vpr/` и `src/frontend/legacy/`

### 2. Структурирование вариантов

- Разобрать каждый вариант на отдельные задания
- Отделить формулировки заданий от ответов и критериев
- Привести к машиночитаемому формату (JSON)

### 3. Урезанный фронтенд

- Поднять минимальный веб-интерфейс:
  - Выбор варианта
  - Показ заданий варианта
  - Поле для ввода ответа
- Фронтенд — статический (HTML + vanilla JS или минимальный бандл), без бэкенда
- Бэкенд не нужен на этом этапе: проверка ответов будет на следующей фазе с ИИ-репетитором

### 4. Следующая фаза (превью)

- Качественная переделка фронтенда
- Прикручивание ИИ-репетитора (LLM с доступом к учебнику через `show_toc`/`get_page`)
- Автоматическая проверка ответов с опорой на учебник (алмазный фундамент)

## Ожидаемый результат

- Варианты ВПР доступны в структурированном виде в репозитории
- Урезанный фронтенд запускается локально и показывает задания
- Всё закоммичено по TDD-циклу
