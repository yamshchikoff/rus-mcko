# Инструментарий постраничной загрузки учебника

## Назначение

LLM (deepseek-v4-pro) использует инструменты `show_toc()` и `get_page()` для навигации по учебнику «Русский язык. 7 класс». Полный текст учебника (~184K токенов) не помещается в контекстное окно (200K), поэтому модель сама решает, какие страницы загрузить для подготовки к МЦКО по конкретной теме.

## Архитектура

```
data/textbook/textbook.json   — единый JSON: meta + toc + pages (0.9 MB)
src/textbook/tools.py         — рантайм: show_toc(), get_page()
src/textbook/build.py         — сборка: python -m src.textbook.build [--force]
src/textbook/_toc_parser.py   — парсинг текста оглавления
src/textbook/_page_extractor.py — вызов pdftotext, разбивка по страницам
src/textbook/constants.py     — пути к PDF, диапазоны страниц
```

## API инструментов

### `show_toc() → str`

Возвращает форматированное оглавление с номерами PDF-страниц:

```
 Русский язык как развивающееся явление — стр. 5
[ПОВТОРЕНИЕ ИЗУЧЕННОГО В 5—6 КЛАССАХ]
  § 1 Синтаксис. Синтаксический разбор предложения — стр. 7
  § 2 Пунктуация. Пунктуационный разбор предложения — стр. 8
...
[МОРФОЛОГИЯ И ОРФОГРАФИЯ. КУЛЬТУРА РЕЧИ]
Причастие
  § 12 Причастие как часть речи — стр. 40
...
```

Формат: секции в [скобках], подсекции с отступом, темы с § и PDF-страницей.

### `get_page(part: int, page: int) → str`

Возвращает сырой текст страницы PDF.

- `part` ∈ {1, 2}
- `page` — номер PDF-страницы (из вывода `show_toc()`)
- `ValueError` при невалидных аргументах

## Структура textbook.json

```json
{
  "meta": {
    "title": "Русский язык. 7 класс",
    "authors": "М.Т. Баранов, Т.А. Ладыженская и др.",
    "year": 2022,
    "publisher": "Просвещение"
  },
  "toc": [
    {
      "type": "section",
      "title": "ПОВТОРЕНИЕ ИЗУЧЕННОГО В 5—6 КЛАССАХ",
      "entries": [
        {
          "type": "topic",
          "number": "§ 1",
          "title": "Синтаксис. Синтаксический разбор предложения",
          "part": 1,
          "pdf_page": 7
        }
      ]
    }
  ],
  "pages": [
    {
      "part": 1,
      "pdf_page": 4,
      "printed_page": 3,
      "text": "сырой текст страницы..."
    }
  ]
}
```

- `toc` — иерархическое: section → subsection → topic (59 тем)
- `pages` — 315 страниц (часть 1: 174, часть 2: 141)
- `pdf_page = printed_page + 1` (смещение из-за обложки)

## Сборка

```bash
python3 -m src.textbook.build          # однократная сборка
python3 -m src.textbook.build --force  # принудительная пересборка
```

Требования: `pdftotext` (poppler-utils), PDF-файлы в `docs/textbook/`.

## Ограничения v1

- Таблицы линеаризованы (pdftotext не сохраняет структуру таблиц)
- Два известных артефакта pdftotext: двойной перевод строки у сносок, лишние пробелы в конце строк
- Оглавление части 2: подсекции не вложены в секции (в TOC части 2 нет ALL CAPS заголовков)
- Толковый словарь (приложение) не индексирован
