## Методология оценки

10 критериев, каждый от 1 до 10. Итоговая оценка — средневзвешенное по формуле в конце документа.

## Критерии

### E1. Извлекаемость текста (вес: ×2.0)

Работает ли `pdftotext` / программный экстрактор на всём документе? Есть ли страницы, с которых текст не извлекается вовсе?

| Балл | Описание |
|------|----------|
| 1-2 | 20%+ страниц не отдают текст — пустой вывод, бинарный мусор |
| 3-4 | 5-20% страниц без текста, остальное с проблемами |
| 5-6 | Текст извлекается со всех страниц, но на отдельных — неполный |
| 7-8 | Все страницы отдают текст, единичные сбои на спецсимволах |
| 9-10 | 100% страниц извлекаются стабильно, текст читаемый без донастройки |

### E2. Точность распознавания символов (вес: ×2.0)

Нет ли ошибок OCR-типа: путаница «и»/«н»/«п», «о»/«а», «с»/«е», «т»/«г»? Нет ли нечитаемых последовательностей?

| Балл | Описание |
|------|----------|
| 1-2 | Массовые ошибки: >10 на страницу, текст требует угадывания |
| 3-4 | Частые ошибки: 3-10 на страницу, смысл местами теряется |
| 5-6 | Редкие ошибки: 1-3 на страницу, общий смысл ясен |
| 7-8 | Единичные ошибки: 1 на 2-3 страницы, в основном на спецсимволах |
| 9-10 | Ошибок распознавания нет — текст идентичен оригиналу |

### E3. Полнота страниц (вес: ×2.0)

Все ли страницы учебника присутствуют? Нет ли обрезанных, пустых, задвоенных страниц?

| Балл | Описание |
|------|----------|
| 1-2 | Отсутствуют целые разделы (10+ страниц подряд) |
| 3-4 | Пропущены отдельные страницы (2-9) или есть задвоения |
| 5-6 | Все страницы на месте, но на некоторых — обрыв текста в середине |
| 7-8 | Все страницы в наличии, текст не обрезан |
| 9-10 | Полное соответствие печатному оригиналу: все 175+ страниц, без потерь |

### E4. Структурная целостность при экстракции (вес: ×1.5)

Сохраняется ли при извлечении деление на параграфы, абзацы, нумерованные списки, заголовки?

| Балл | Описание |
|------|----------|
| 1-2 | Текст сливается в одну простыню — нет ни абзацев, ни заголовков |
| 3-4 | Разрывы абзацев есть, но заголовки и нумерация потеряны |
| 5-6 | Абзацы и крупные заголовки сохранены, нумерация местами сбита |
| 7-8 | Структура в основном сохранена, мелкие дефекты на стыках страниц |
| 9-10 | Полная структура: параграфы → абзацы → списки → подпункты, без дефектов |

### E5. Чистота от артефактов (вес: ×1.0)

Нет ли в извлечённом тексте мусора: колонтитулов, номеров страниц, водяных знаков, рекламных вставок, служебных меток PDF?

| Балл | Описание |
|------|----------|
| 1-2 | Артефакты занимают >20% текста — колонтитулы в каждой строке |
| 3-4 | Много мусора: номера страниц, заголовки глав в теле текста, мета-вставки |
| 5-6 | Умеренно: колонтитулы и номера страниц примешиваются, но их можно отфильтровать |
| 7-8 | Минимум артефактов: редкие вкрапления, легко чистятся постобработкой |
| 9-10 | Текст чист — ни колонтитулов, ни номеров, ни мусора |

### E6. Качество кодировки (вес: ×1.5)

Корректна ли кодировка извлечённого текста? Нет ли кракозябр, битых UTF-8 последовательностей?

| Балл | Описание |
|------|----------|
| 1-2 | Текст нечитаем: сплошные кракозябры, неверная кодовая страница |
| 3-4 | Местами читаем, местами битые символы — требует перекодировки |
| 5-6 | В основном UTF-8 корректен, редкие сбои на спецсимволах |
| 7-8 | Кодировка везде верна, включая кириллицу и знаки ударения |
| 9-10 | Безупречная кодировка: UTF-8 clean, все символы на своих местах |

### E7. Порядок и поток текста (вес: ×1.0)

Правильный ли порядок строк? Нет ли разрывов в середине предложения, перепутанных колонок, переставленных абзацев?

| Балл | Описание |
|------|----------|
| 1-2 | Порядок разрушен: колонки перемешаны, строки в обратном порядке |
| 3-4 | Частые нарушения порядка: абзацы переставлены, текст читается нелинейно |
| 5-6 | В основном порядок верен, но есть разрывы в середине предложений |
| 7-8 | Порядок корректен, единичные артефакты на границах страниц |
| 9-10 | Линейный порядок идеален: текст читается как в оригинале |

### E8. Обработка спецсимволов и лингвистической нотации (вес: ×1.0)

Корректно ли извлекаются: буквы ё/Ё, знаки ударения, фонетическая транскрипция, символы разбора (цифровые индексы, стрелки, скобки), курсив/полужирный как разметка?

| Балл | Описание |
|------|----------|
| 1-2 | Спецсимволы потеряны или заменены на мусор |
| 3-4 | Базовый текст читаем, но все лингвистические пометы утеряны |
| 5-6 | Буква ё сохранена, ударения потеряны, индексы нестабильны |
| 7-8 | Большинство спецсимволов сохранено, включая ударения |
| 9-10 | Полное сохранение: ё, ударения, индексы разбора, транскрипция |

### E9. Извлекаемость таблиц и схем (вес: ×0.5)

Корректно ли извлекается текст из таблиц, схем, врезок с правилами?

| Балл | Описание |
|------|----------|
| 1-2 | Таблицы и схемы — пустые места или сплошной мусор |
| 3-4 | Текст таблиц извлекается фрагментарно, ячейки перемешаны |
| 5-6 | Текст таблиц читаем, но структура строк/столбцов потеряна |
| 7-8 | Таблицы извлекаются с различением строк, схемы — с читаемым текстом |
| 9-10 | Таблицы и схемы сохраняют структуру: строки, столбцы, врезки — всё на месте |

### E10. Однородность качества между частями (вес: ×1.5)

Одинаково ли качество экстракции в Части 1 и Части 2? Нет ли расхождений в кодировке, структуре, артефактах?

| Балл | Описание |
|------|----------|
| 1-2 | Части радикально различаются: одна читаема, вторая — нет |
| 3-4 | Значительные расхождения в качестве между частями |
| 5-6 | Обе части в целом читаемы, но есть заметные различия в артефактах |
| 7-8 | Части близки по качеству, мелкие расхождения |
| 9-10 | Идентичное качество: части неразличимы по уровню экстракции |

## Формула итоговой оценки

```
Q = (E1×2.0 + E2×2.0 + E3×2.0 + E4×1.5 + E5×1.0 + E6×1.5 + E7×1.0 + E8×1.0 + E9×0.5 + E10×1.5) / 14.0
```

Сумма весов = 14.0, нормировка на 14.0 даёт итоговую оценку в диапазоне 1-10.

## Критические пороги

| Диапазон Q | Вердикт | Действие |
|-------------|---------|----------|
| 1.0 – 3.9 | Непригоден | Искать другой источник учебника |
| 4.0 – 5.9 | Условно пригоден | Требуется ручная вычистка или замена проблемных страниц |
| 6.0 – 7.9 | Пригоден | Допустимо после постобработки артефактов |
| 8.0 – 10.0 | Отлично | Готов к использованию в алмазном фундаменте |

Кроме того, любой критерий с оценкой ≤2 является блокирующим независимо от итогового Q.

## Протокол оценки

Оценка проведена 2026-06-04. Каждый критерий оценён с обоснованием и примерами.

### E1. Извлекаемость текста — **9/10** (вес ×2.0 = 18.0)

**Обоснование:** `pdftotext` извлекает текст со 100% страниц обеих частей (185/185 стр. Часть 1, 149/149 стр. Часть 2). 8 страниц в Части 1 и 7 в Части 2 содержат <50 символов — это обложка, титульные страницы, выходные данные. Все содержательные страницы (2–176 в Ч1, 2–144 в Ч2) извлекаются стабильно.

**Проблемные страницы:** отсутствуют. Пустые/около-пустые страницы — норма для front/back matter.

**Оценка 9, а не 10:** небольшое количество страниц с минимальным текстом (обложка), хотя это ожидаемо.

---

### E2. Точность распознавания символов — **9/10** (вес ×2.0 = 18.0)

**Обоснование:** Учебник — цифровой оригинал (iTextSharp), не скан. На 460 000+ символов обнаружено ровно 2 артефакта:
- `однокласcники` — латинская 'c' вместо русской 'с' (1 случай)
- `cилуэт` — латинская 'c' вместо русской 'с' (1 случай)

Соотношение Latin/Cyrillic: 0.0011 (Ч1) и 0.0019 (Ч2) — весь латинский текст легитимен (ISBN, URL, аббревиатуры). Длинные слова (18+ символов) — реальные русские сложные слова: *культурологического*, *усовершенствованный*, *церковнославянском*, *противопоставление*.

**Проблемные места:**
```
однокласcники  → должно быть: одноклассники (латинская 'c')
cилуэт         → должно быть: силуэт (латинская 'c')
```

**Оценка 9, а не 10:** 2 известных артефакта на 460K символов (частота ошибок 0.0004%).

---

### E3. Полнота страниц — **9/10** (вес ×2.0 = 18.0)

**Обоснование:** PDF содержит 185 страниц (Часть 1) при заявленных 175 содержательных — разница в 10 страниц приходится на обложку, титул, выходные данные и оглавление. Аналогично Часть 2: 149 страниц PDF. Текст не обрезан, нет задвоений. Содержание проверено по ключевым терминам: все разделы 7 класса присутствуют (причастие — 86 упоминаний, деепричастие — 25, наречие — 28, предлог — 118, союз — 138, частица — 34, междометие — 11, категория состояния — 10).

**Оценка 9, а не 10:** расхождение заявленных и фактических страниц (175 vs 185) требует уточнения, хотя разница объяснима front/back matter.

---

### E4. Структурная целостность при экстракции — **8/10** (вес ×1.5 = 12.0)

**Обоснование:** Структура хорошо сохранена:
- 1118 абзацных разрывов в Части 1
- 95 маркеров параграфов (§N)
- 616 номеров упражнений
- 684 вопросительных знака
- Заголовки разделов извлекаются как отдельные строки

Пример хорошей структуры:
```
§ 1. Синтаксис.

Что изучает синтаксис?
Чем отличается словосочетание от предложения?
```
Нумерация упражнений, вопросов и параграфов сохранена.

**Проблемы:** единичные случаи слияния слов на стыках: `тольприсутствовать` (вероятно: «только присутствовать»).

**Оценка 8, а не 10:** редкие артефакты слияния слов, возможна потеря некоторых элементов оформления (рамки, цветовые плашки с правилами) при текстовой экстракции.

### E5. Чистота от артефактов — **8/10** (вес ×1.0 = 8.0)

**Обоснование:** Текст чист от системного мусора:
- 0 упоминаний названия учебника/авторов в теле страниц (не считая титула)
- 0 вхождений ISBN в содержательных страницах

Пример чистого текста:
```

```
Номера упражнений являются легитимным контентом.

**Оценка 8, а не 10:** отдельные номера страниц могут примешиваться к тексту (типично для pdftotext), хотя в данном случае их мало.

Пример хорошего потока (стр. 125):

### E8. Обработка спецсимволов и лингвистической нотации — **7/10** (вес ×1.0 = 7.0)

**Обоснование:**

- **Тире:** 1173 вхождения — хорошо
- **Фонетические скобки:** 21 вхождение — присутствуют
- **Знаки ударения:** 0 — отсутствуют (вероятно, их нет и в оригинале)
- **Надстрочные/подстрочные индексы:** 0 — потеряны при экстракции (в печатном учебнике индексы используются для морфемного разбора: приставка¹, корень² и т.п.)

**Оценка 7, а не 10:** потеря индексов разбора снижает пригодность для автоматической проверки некоторых типов заданий. Буква ё сохранена отлично.

### E9. Извлекаемость таблиц и схем — **5/10** (вес ×0.5 = 2.5)

**Обоснование:** Таблицы не определяются как структурные элементы (0 страниц с табличной разметкой). При этом текстовое содержимое таблиц извлечено — 200 упоминаний грамматических категорий (падеж, род, число, склонение, спряжение, разряд). Текст таблиц линеаризован: ячейки читаются подряд, структура строк и столбцов утеряна.

**Оценка 5:** содержимое таблиц доступно, но без структуры. Для алмазного фундамента потребуется ручная или полуавтоматическая разметка табличного материала.

**Меры:** постобработка с поиском паттернов «термин — определение» или ручная разметка критических таблиц (склонение причастий, разряды наречий, Н/НН).
