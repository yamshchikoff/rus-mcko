# Априорная шкала качества учебника

Учебник: Баранов, Ладыженская, Тростенцова и др. «Русский язык. 7 класс» (Просвещение, 2022).
Шкала определена до чтения учебника, во избежание bias.

## Методология оценки

10 критериев, каждый оценивается от 1 до 10. Итоговая оценка — среднее арифметическое.

## Критерии

### 1. Структурная полнота (вес: ×1.0)

Охват всех тем программы 7 класса: причастие, деепричастие, наречие, категория состояния, служебные части речи (предлог, союз, частица), междометия, повторение синтаксиса и пунктуации.

| Балл | Описание |
|------|----------|
| 1-2 | Отсутствуют целые крупные разделы |
| 3-4 | Крупные разделы присутствуют, но есть пробелы в подтемах |
| 5-6 | Все разделы на месте, часть подтем раскрыта поверхностно |
| 7-8 | Полный охват тем, большинство подтем раскрыто |
| 9-10 | Исчерпывающий охват: все темы и подтемы ФГОС, плюс дополнительный материал |

### 2. Качество правил и формулировок (вес: ×1.0)

Точность, полнота и однозначность грамматических правил и определений.

| Балл | Описание |
|------|----------|
| 1-2 | Правила содержат фактические ошибки или пропуски ключевых условий |
| 3-4 | Правила в основном верны, но есть неточности или двусмысленности |
| 5-6 | Правила корректны, но формулировки местами громоздки или сухи |
| 7-8 | Правила точны, полны и сформулированы ясно |
| 9-10 | Правила безупречны: точны, полны, лаконичны, с мнемоническими опорами |

### 3. Методическая проработка упражнений (вес: ×1.0)

Качество, разнообразие и градация упражнений по сложности.

| Балл | Описание |
|------|----------|
| 1-2 | Однотипные упражнения, нет градации сложности |
| 3-4 | 2-3 типа упражнений, градация слабо выражена |
| 5-6 | Разнообразие типов, есть базовая градация «от простого к сложному» |
| 7-8 | Богатое разнообразие, чёткая прогрессия, творческие задания |
| 9-10 | Идеальный баланс: репродуктивные → конструктивные → творческие, с рефлексией |

### 4. Близость к формату МЦКО (вес: ×1.5)

Насколько материал и типы заданий соответствуют формату контрольных работ МЦКО для 7 класса.

| Балл | Описание |
|------|----------|
| 1-2 | Полное несовпадение с форматом МЦКО |
| 3-4 | Лишь некоторые задания отдалённо напоминают МЦКО |
| 5-6 | Примерно половина типов заданий релевантна МЦКО |
| 7-8 | Большинство типов заданий соответствует МЦКО |
| 9-10 | Прямая корреляция: упражнения системно готовят к каждому типу заданий МЦКО |

### 5. Доступность изложения для 12-13 лет (вес: ×1.0)

Соответствие языка учебника возрастным особенностям семиклассников.

| Балл | Описание |
|------|----------|
| 1-2 | Текст перегружен терминологией, синтаксически сложен для возраста |
| 3-4 | Местами слишком академичен, требует взрослого посредника |
| 5-6 | В целом доступен, но отдельные фрагменты трудны для самостоятельного чтения |
| 7-8 | Ясный, живой язык, примеры из понятного подростку опыта |
| 9-10 | Образцовый: язык удерживает внимание, объясняет сложное просто, без упрощений |

### 6. Культурологический компонент (вес: ×0.5)

Качество и уместность текстов о культуре, литературных отрывков, воспитательный потенциал.

| Балл | Описание |
|------|----------|
| 1-2 | Тексты формальны, бессодержательны или отсутствуют |
| 3-4 | Минимальное присутствие культурного материала, без системы |
| 5-6 | Достаточный набор текстов о культуре, но подбор не всегда удачен |
| 7-8 | Богатый культурный материал, тексты русских классиков, информация о языке и культуре |
| 9-10 | Выдающаяся подборка: тексты формируют картину мира, связь языка с историей и культурой |

### 7. Навигация и визуальное оформление (вес: ×0.5)

Качество оглавления, рубрикации, шрифтовых выделений, схем и таблиц.

| Балл | Описание |
|------|----------|
| 1-2 | Отсутствие навигации, монотонный текст без визуальной структуры |
| 3-4 | Минимальная рубрикация, редкие выделения |
| 5-6 | Приемлемая структура: параграфы, заголовки, базовые выделения |
| 7-8 | Хорошая навигация: условные обозначения, таблицы, схемы, цветовые акценты |
| 9-10 | Образцовая: интуитивная навигация, богатый визуальный аппарат, инфографика |

### 8. Качество текстового слоя для машинной обработки (вес: ×1.0)

Пригодность PDF для извлечения текста программными средствами (pdftotext, python).

| Балл | Описание |
|------|----------|
| 1-2 | Скан без OCR — текст не извлекается |
| 3-4 | Текст извлекается с ошибками, потерей структуры |
| 5-6 | Текст извлекается, но есть проблемы с порядком абзацев или кодировкой |
| 7-8 | Чистое извлечение: текст, структура, нумерация сохраняются |
| 9-10 | Идеальное: машиночитаемый текст с полной структурой, возможна потоковая обработка |

### 9. Полнота орфографических и пунктуационных правил (вес: ×1.0)

Охват правил орфографии и пунктуации, предусмотренных программой 7 класса.

| Балл | Описание |
|------|----------|
| 1-2 | Ключевые правила 7 класса отсутствуют |
| 3-4 | Правила есть, но без систематизации, часть важных случаев упущена |
| 5-6 | Основные правила охвачены, есть некоторые пробелы в частных случаях |
| 7-8 | Полный охват: причастия (Н/НН, НЕ), деепричастия, наречия, служебные части речи |
| 9-10 | Исчерпывающий охват с особыми случаями, исключениями и комментариями |

### 10. Связность и преемственность (вес: ×0.5)

Логика перехода от темы к теме, связь с программой 5-6 классов и подготовка к 8 классу.

| Балл | Описание |
|------|----------|
| 1-2 | Темы механически следуют друг за другом без логики |
| 3-4 | Формальная связность, но без содержательных мостиков между темами |
| 5-6 | Приемлемая логика: повторение пройденного, новая тема, закрепление |
| 7-8 | Хорошая преемственность: явные отсылки к материалу 5-6 классов, подготовка к 8 классу |
| 9-10 | Образцовая: каждая тема мотивирована предыдущей и готовит к следующей, системный взгляд на язык |

## Формула итоговой оценки

```
Q = (K1×1.0 + K2×1.0 + K3×1.0 + K4×1.5 + K5×1.0 + K6×0.5 + K7×0.5 + K8×1.0 + K9×1.0 + K10×0.5) / 9.0
```

Сумма весов = 9.0, нормировка на 9.0 даёт итоговую оценку в диапазоне 1-10.

## Протокол оценки

Оценка будет проведена после команды пользователя. Каждый критерий оценивается с кратким обоснованием и ссылкой на конкретные места учебника.
