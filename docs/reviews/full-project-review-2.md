## 3. Новые находки

### 3.1. `_serve_toc` не имеет path traversal защиты (лёгкое)

**Файл:** `server.py:186-194`

`_serve_toc` читает `self.get_textbook()` напрямую, не проходя через `_serve_static`. Это безопасно (данные из памяти), но `/api/toc` не имеет защиты от обхода пути — впрочем, он и не принимает параметров пути.

### 3.2. `compact_history` — `import json` внутри функции (лёгкое)

**Файл:** `compaction.py:23`

```python
import json as _json
```

Импорт внутри `estimate_tokens` на каждом вызове. В цикле tool-use функция вызывается на каждой итерации. Лучше вынести на уровень модуля.

### 3.3. `saveChatHistory` с квотой: сообщение может потеряться (лёгкое)

**Файл:** `index.html:175-181`

При `QuotaExceededError` сообщение молча теряется — чат не знает, что запись не удалась. При следующей загрузке истории последнего сообщения нет. Не критично, но может удивить пользователя.
