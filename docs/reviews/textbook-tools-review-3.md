## Новые находки

### M3. Подсекции не вложены в родительские секции

**Файл:** `src/textbook/_toc_parser.py:67-78`
**Серьёзность:** major (искажает иерархию TOC)

**Симптом.** `show_toc()` выводит:

```
[МОРФОЛОГИЯ И ОРФОГРАФИЯ. КУЛЬТУРА РЕЧИ]
Причастие
  § 12 Причастие как часть речи — стр. 40
  ...
Деепричастие
  § 28 Деепричастие как часть речи — стр. 98
Наречие
  § 34 Наречие как часть речи — стр. 120
```

Подсекции `Причастие`, `Деепричастие`, `Наречие` отображаются без отступа — на том же уровне, что и секции `[...]`. Правильное поведение: они должны быть вложены под `[МОРФОЛОГИЯ И ОРФОГРАФИЯ. КУЛЬТУРА РЕЧИ]` с отступом в 2 пробела.

**Корень.** В `parse_toc()` переменная `current_section` всегда указывает на `entries` (верхний уровень). При обнаружении секции `current_subsection` обновляется на `section['entries']` (для вложения тем), но `current_section` НЕ обновляется:

```python
# строка 67-70 текущего кода
if _is_section_header(stripped):
    section = {'type': 'section', 'title': stripped, 'entries': []}
    current_section.append(section)          # добавляет секцию в entries
    current_subsection = section['entries']  # темы пойдут под секцию
    continue                                 # НО current_section остался = entries!

# строка 74-78
if _is_subsection_header(stripped):
    subsection = {'type': 'subsection', 'title': stripped, 'entries': []}
    current_section.append(subsection)       # ← добавляет подсекцию в entries (верхний уровень!)
    current_subsection = subsection['entries']
    continue
```

На строке 76 `current_section` всё ещё равен `entries`, поэтому подсекция добавляется на верхний уровень, а не внутрь секции.

**Исправление:**

```python
if _is_section_header(stripped):
    section = {'type': 'section', 'title': stripped, 'entries': []}
    entries.append(section)                  # секция всегда на верхнем уровне
    current_section = section['entries']     # ← добавлено: подсекции идут под секцию
    current_subsection = section['entries']  # темы без явной подсекции — тоже под секцию
    continue
```

При обнаружении новой секции она явно добавляется в `entries` (верхний уровень), а `current_section` заменяется на `section['entries']`. Последующие подсекции попадают внутрь секции.

**Влияние на Part 2.** В Part 2 нет ALL CAPS секций — все заголовки Title Case, поэтому парсятся как подсекции. `current_section` остаётся равен `entries` (верхний уровень), подсекции Part 2 добавляются на верхний уровень. Поведение для Part 2 не меняется. ✓

**Влияние на тесты.** Все 52 теста продолжат проходить — тесты используют `_flatten()` для поиска подсекций и не проверяют иерархию вложенности. Рекомендуется добавить тест на вложенность.

### m2. `entry.get('pdf_page', '?')` не защищает от `None`

**Файл:** `src/textbook/tools.py:42`
**Серьёзность:** minor (не триггерится на текущих данных — 0 тем с `pdf_page: null`)

```python
page = entry.get('pdf_page', '?')
```

Метод `.get(key, default)` возвращает `default` **только если ключ отсутствует**. Если ключ есть, но значение — `None`, возвращается `None`. Тогда `f'...стр. {page}'` даст `'...стр. None'`.

В `_make_topic` (строка 181-184) `pdf_page` может быть `None`, когда `printed_page is None` — т.е. для темы без номера страницы (flush pending topic без номера). На сегодняшних данных таких тем в JSON нет, но они могут появиться при изменении PDF.

**Исправление:**

```python
page = entry.get('pdf_page')
if page is None:
    page = '?'
```

### m3. `_check_pdftotext()` вызывается дважды при каждой сборке

**Файл:** `src/textbook/_page_extractor.py:30`
**Серьёзность:** minor (производительность сборки)

`extract_all_pages()` вызывается дважды (по одному разу на часть), и каждый вызов запускает `pdftotext -v` для проверки доступности. Достаточно одного вызова при импорте или первого явного вызова.

**Исправление:** сделать `_check_pdftotext()` однократным — через `_pdftotext_checked` флаг на уровне модуля.
