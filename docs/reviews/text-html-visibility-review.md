## Путь данных

```
sdamgia API (поле text)
  → extract.py (text_html = task_data.get('text', ''))
    → variants.json (text_html)
      → фронтенд loadVariant (t.text_html)
        → renderTask (показ в карточке)
        → POST /api/review (text_html в payload)
          → _handle_review (tasks без трансформации)
            → execute_review → build_review_messages (Опорный текст)
              → DeepSeek API
```

Путь неразрывный на всём протяжении. Ни одно звено не теряет `text_html`.

## Влияние на токены

Добавление `text_html` в сообщение ревьюера увеличит входные токены. Для К2/К3 опорные тексты — ~800–1200 символов каждый. На 7 заданий: ~2 текста × ~1000 символов ≈ 2000 символов ≈ 570 токенов. Некритично при `max_tokens: 32768`.
